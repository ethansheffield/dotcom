ethansheffield.com
==================

Personal site for Ethan Sheffield.

Built with plain HTML, CSS, and JavaScript — no build step required.
Pages
-----
/               Homepage (intro, about, expertise, tools, journal preview)
/about/         Biography, values, background
/tech/          Services and technology areas
/blog/          Journal / blog index
/text-editor-setup/         Blog post: text editor setup
/building-a-home-network/   Blog post: home networking
/contact/       Contact and social links

Assets
------
css/vendor.css  PrismJS 1.20.0 (okaidia theme) + Swiper 6.4.5
css/styles.css  Custom styles
js/plugins.js   PrismJS + MoveTo 1.8.2 (vendored)
js/main.js      Site JS (preloader, mobile nav, smooth scroll, etc.)

Deployment
----------
Hosted on GitHub Pages. Custom domain: ethansheffield.com (see CNAME).
